## 8. Pitfalls learned

- Run Python with `PYTHONIOENCODING=utf-8` (Devanagari). `uv run pytest -q <files>`; system Python lacks dependencies, so Codex reads code but cannot run tests (paste evidence in its prompt).
- **Codex:** Git Bash `codex exec --sandbox read-only -C "D:/aai work/granthstudio" --add-dir D:/kaggle_upload/repo_research -o <file> - < prompt.txt` (run in the background; never add the secrets folders).
