## 9. Pitfalls learned (save time)

- Run Python with `PYTHONIOENCODING=utf-8` (Devanagari). Use `uv run pytest -q <file>` (system Python lacks pytest/jsonschema, so Codex cannot run tests; it reads code).
- Codex (Git Bash): `codex exec --sandbox read-only -C "D:/aai work/granthstudio" --add-dir D:/kaggle_upload/repo_research -o <file> - < prompt.txt`; PowerShell has no `<`: `Get-Content prompt.txt -Raw | codex exec --sandbox read-only -C "D:/aai work/granthstudio" --add-dir D:/kaggle_upload/repo_research -o <file> -`. Ask for SAFE TO RUN / NOT SAFE plus BLOCKER/MAJOR findings; it found a real bug in every script so far. Do not put secrets folders in `--add-dir`.
- Background jobs notify when done; do not poll. Keep NVIDIA calls small or streamed. Count ledger reservations by latest record per id.
