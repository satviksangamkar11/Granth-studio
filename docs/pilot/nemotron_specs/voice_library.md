## Security rules (binding)

If none: raise SystemExit("NOT_RUN: no ElevenLabs key ..."). ## API
- `load_key(env=None, secrets_dir=Path("D:/aai work/secrets/elevenlabs")) -> str`.
- `fetch_voices(key, http=None) -> list[dict]`: GET `https://api.elevenlabs.io/v1/voices` with header `xi-api-key: <key>` and `Accept: application/json`; `http` is an injectable callable `http(url, headers) -> (status:int, body:bytes)` (default uses urllib with a 60 s timeout); status != 200 raises RuntimeError(f"ElevenLabs list voices failed: HTTP {status}") WITHOUT the key or the headers; the JSON body has key "voices": a list of dicts (return that list; a missing key gives []).
- `normalize(raw: dict) -> dict`: from one raw voice dict (all fields optional) return {"voice_id": str, "name": str, "category": str, "gender": str, "age": str, "accent": str, "descriptive": str, "use_case": str, "description": str, "marathi_verified": bool, "hindi_verified": bool}. Mapping: `labels` is a dict (may be absent): gender/age/accent/descriptive/use_case come from labels (missing -> ""); `description` from raw["description"] or "" (None -> ""); `verified_languages` is a list of dicts with a "language" (e.g. "mr", "hi" or "Marathi"/"Hindi") and/or "locale"; marathi_verified is True if any entry has language or locale starting (case-insensitive) with "mr" or equal to "marathi"; hindi_verified likewise with "hi"/"hindi". A raw voice without a voice_id is skipped by `build_library`.
- `build_library(raw_voices: list[dict], cast: dict[str, str], assignments: dict[str, list[str]] | None = None, generated: str = "") -> dict`: `cast` maps voice_key -> voice_id for the already-assigned cast voices (from `canon/audio/A1_eleven_voices.json`, the "mr" mapping: narrator, gajanan, bankatlal, damodarpant). `assignments` maps voice_key -> list of character ids using it (default: for each cast key, [that key]). Output {"version": 1, "generated": generated, "source": "elevenlabs list voices", "voices": [records sorted by voice_key]}. Record = normalize() fields plus: `voice_key` (the cast key when the voice_id is in `cast`, else a slug of the name: lowercase, non-alphanumerics -> "_", stripped of leading/trailing "_", with the voice_id's first 4 characters appended when the slug is already used), `assigned_to` (list, [] when unassigned), `status` "ASSIGNED" if assigned_to else "AVAILABLE", `owner_note` "" (the owner edits descriptions later). Every cast voice_id absent from the account list is kept as a record with name = its key, status "MISSING_FROM_ACCOUNT", assigned_to as given, empty description and false flags, so nothing is lost. Duplicate voice_ids in the input appear once.
- `write_library(path, library, overwrite=False) -> None`: refuses (FileExistsError) when the file exists and overwrite is False; creates the folder; writes atomically (temp file in the same folder + os.replace), UTF-8 JSON, indent=1, ensure_ascii=False, sorted keys.
- `main(argv=None) -> int`: CLI `--cast PATH` (default `canon/audio/A1_eleven_voices.json` under the repository root; use its "mr" mapping), `--out PATH` (default `canon/series/voices.json`), `--overwrite`, `--dry-run` (build and print the summary, write nothing). Steps: load_key, fetch_voices, build_library (generated = today's date YYYY-MM-DD), write unless dry-run. Print ONLY a summary: number of voices, then one line per voice "voice_key | name | gender | age | marathi_verified | hindi_verified | status" (descriptions are NOT printed). Never print the key. Return 0.
